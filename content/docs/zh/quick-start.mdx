# 5分钟快速开始

本教程将引导你在 5 分钟内创建一个标准的 **ISO 4401-03 (NG6)** 换向阀单联阀块，完成底孔布设与流道连通，并执行壁厚干涉检查。

---

## 准备工作：三维视口操作手势

在开始布孔前，熟悉以下标准三维视口操作可显著提高设计效率：

| 操作手势 | 动作响应 | 说明 |
| :--- | :--- | :--- |
| **鼠标左键单击** | 拾取面 / 选中孔腔 | 选中阀块安装面或具体孔腔以编辑坐标与深度参数 |
| **鼠标右键 / 中键按住拖拽** | 自由三维旋转视角 | 360° 观察阀块各面及内部半透明流道走向 |
| **鼠标滚轮滚动** | 视口平滑缩放 | 放大检查相贯线交截区域或缩小纵观全局 |
| **Shift + 鼠标中键拖拽** | 视口平移 (Pan) | 平行移动三维舞台中心 |
| **双击空白区域 / 空格键** | 视角复位 | 快速恢复为等轴测 (Isometric) 标准透视视角 |

---

## 步骤一：新建工程与定义毛坯尺寸

1. 启动 SureFlow 客户端，点击主欢迎页的 **「新建工程」**；
2. 在弹出设置中选择基体材质：`45# 优质碳素钢`（系统预设许用应力与密度，亦可选 `6061-T6 铝合金` 或 `QT500 球墨铸铁`）；
3. 输入毛坯外形尺寸（长 × 宽 × 高）：
   - 长度 $X$ = **120 mm**
   - 宽度 $Y$ = **100 mm**
   - 高度 $Z$ = **80 mm**
4. 点击 **「确认创建」**，中央视口立即生成具备金属微光质感的实体长方体。

---

## 步骤二：放置标准 ISO 4401 阀腔接口

1. 在左侧工具箱展开 **「标准孔腔库」**；
2. 展开 `板式阀安装面` 目录，找到 `ISO 4401-03 (CETOP 03 / NG6)`；
3. 将该标准件拖拽至阀块的 **顶面（+Z 面）**；
4. 在右侧参数检查器中设定安装中心坐标：$X = 60\text{ mm}$, $Y = 50\text{ mm}$；
5. 软件自动切削生成 4 个紧固螺钉孔及 4 个油口沉孔：`P`（进油口）、`T`（回油口）、`A`（工作口 A）、`B`（工作口 B）。

---

## 步骤三：布设进出油管接头孔

1. 旋转视角至阀块侧面（例如 -X 侧面或 -Y 侧面）；
2. 从孔腔库的 `螺纹管接头` 列表中拖出 `G 3/8" (BSPP)` 标准直螺纹孔；
3. 依次布置进油接头 $P_0$ 与回油接头 $T_0$：
   - 设定定位坐标与打孔深度（例如深度 45 mm）；
   - 视口中以半透明圆柱体即时显示孔道空间走势。

---

## 步骤四：孔道相贯与工艺辅助孔

1. 调整顶面 `P` 孔与侧面 $P_0$ 孔的深度，使其在阀块内部形成正交相贯交汇；
2. 若两个油口处于不同空间标高无法直接相通：
   - 从外部基准面引入一根工艺辅助钻孔；
   - 在相交完成后，为工艺孔入口添加 `SAE` 或 `公制` 螺塞堵头（Plugging Head）；
3. 视口中将即时计算相贯椭圆截面，并用明亮高光显示油液流通通道。

---

## 步骤五：验证安全壁厚与干涉排查

1. 观察右侧 **「几何检查面板」**：
   - **最小壁厚测量值**：显示当前所有孔壁间的绝对最小欧氏距离（如 `5.2 mm`）；
   - **安全阈值对比**：当前系统设定承压安全壁厚阈值为 `≥ 3.5 mm`，指示灯显示为绿色安全；
   - **空间干涉报警**：若存在非预期贯穿或壁厚低于阈值，违规孔壁将呈现醒目黄色/红色高亮报警；
2. 确认校验无误后，点击右上角 **「导出」** → **「导出 STEP 实体 (.stp)」** 保存模型，可直接交付下游机床加工或 SolidWorks/NX 总成装配。
