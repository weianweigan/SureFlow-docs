# SureFlow 系统概览

**SureFlow** 是一款面向工程机械、机床工业、重型装备及流体动力控制领域的**新一代专业级液压阀块（Hydraulic Manifold Block）三维设计与孔道校验软件**。

传统液压阀块设计严重依赖二维 CAD 投影出图与人工空间想象，容易出现孔道碰撞穿透、承压壁厚不足、深孔交贯偏斜以及工艺堵孔繁多等难题。SureFlow 以现代参数化几何建模为基础，为液压工程师提供集「外形定义、标准孔腔库布孔、实时壁厚干涉检查、高保真 STEP 实体导出」于一体的直观工作流。

---

## 核心功能特性

### 1. 参数化外形与基准面定义
- **多样化几何毛坯**：支持规则长方体毛坯的快速参数化设定，支持 L 型与 T 型等阶梯异形阀块外形；
- **装配基准面拾取**：自由选择阀块顶面（+Z）、底面（-Z）及各侧面（±X、±Y）作为装配基准面；
- **外部参考模型导入**：支持导入主机机械结构或安装架的 STEP 模型作为参考几何，便于现场避让与接口对齐。

### 2. 标准工业孔腔库与智能布孔
- **内置标准插装阀孔**：涵盖主流螺纹插装阀孔腔（如二通插装阀、Sun、HydraForce 等工业规格）；
- **ISO 4401 板式阀安装面**：内置 NG6（CETOP 03）、NG10（CETOP 05）等标准换向阀与叠加阀孔系模板；
- **标准管接头与法兰**：支持 SAE 直螺纹（ISO 11926）、公制螺纹（ISO 6149）、高压法兰（SAE J518）与定位销孔；
- **企业专属库扩充**：支持用户基于清晰的 JSON 规范自定义孔腔台阶、锥角、倒角及油口语义标注。

### 3. 实时毫秒级安全壁厚与干涉检查
- **动态三维碰撞检测**：在拖拽调整任意孔腔空间位置、孔深或角度时，后台几何引擎毫秒级实时检测孔间干涉与贯通状态；
- **承压壁厚安全核算**：结合回路工作压力等级（如常规 16~31.5 MPa，超高压 70 MPa）与材质屈服强度，实时计算任意孔壁间最小距离并提供色谱安全告警；
- **半透明三维剖视**：提供交互式空间透视与切削预览，孔道交贯状态一览无余。

### 4. 工业级高保真 STEP 实体导出
- **标准 STEP 实体**：基于 OpenCASCADE (OCCT) 工业级几何内核，直接导出标准 ISO 10303 (AP203 / AP214) 实体文件；
- **CAD 软件无缝互通**：导出模型在 SolidWorks、Siemens NX、Creo、CATIA 中可直接进行零件编辑、工程图投影及总成装配；
- **钻孔制造工序表**：自动输出孔道编号、油口语义、打孔坐标、钻头直径、孔深工步与沉孔规格明细。
