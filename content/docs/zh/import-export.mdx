# 导入与导出格式规范

SureFlow 基于 OpenCASCADE (OCCT) 工业级几何内核，严格遵循国际标准组织（ISO）的数据交换协议，保障工程数据在主流机械 CAD 系统与数控加工中心之间的无损流转。

---

## 导出格式与工业交付

### 1. STEP 实体模型 (`.stp` / `.step`)

- **遵循标准**：
  - **ISO 10303-214 (AP214)**：广泛用于汽车、通用机械与模具行业，完整包含零件实体几何、拓扑关系与分层颜色标注；
  - **ISO 10303-203 (AP203)**：具备通用兼容性的边界表示（B-Rep）实体模型；
- **几何精度保障**：
  - 孔腔与通道相贯切削保留解析曲面（Cylinder / Cone / Torus）数学精度，不产生多边形网格离散化误差；
- **下游主流 CAD 兼容**：
  - 导出的 STEP 文件可直接在 **SolidWorks**、**Siemens NX**、**PTC Creo**、**CATIA**、**Autodesk Inventor** 中打开，作为标准零件参与设备总成装配，亦可直接出具二维工程图并标注形位公差。

### 2. SureFlow 原生工程文件 (`.sureflow`)

- 保存阀块完整的参数化设计历史：
  - 毛坯外形尺寸与基体材料属性；
  - 各面上布设的标准孔腔实例及其拓扑坐标；
  - 油口语义标签（P、T、A、B 等）与逻辑连通关系；
  - 最小安全壁厚自定义阈值。
- 支持团队成员之间的工程方案复用与后期迭代修改。

### 3. 数控钻孔加工参数表 (`.csv` / `.xlsx`)

导出直接面向车间工艺员与数控编程人员的工序清单，每行包含：
- **孔位编号**：如 `Hole-01`、`Cavity-DG16-01`；
- **所属油路**：如 `P_MAIN`、`T_DRAIN`；
- **加工基准面**：`+Z`、`-Z`、`+X`、`-X` 等；
- **起始坐标**：在基准面上的二维平面坐标 $(X, Y)$ 及绝对空间原点坐标；
- **轴向钻孔矢量**：法向垂直或斜孔空间方向角；
- **刀具与工步参数**：主钻头直径 $D$、深孔有效深度 $H$、扩孔沉孔规格（螺纹底孔、沉头台阶、密封倒角）与推荐转速/进给提示。

## 导入与参考模型

### 1. 外部机械环境参考体导入 (`.step` / `.stp`)

- 在液压阀块嵌入复杂的整机设备（如挖掘机上车架、注塑机锁模机构、风电机舱底座）时，可导入周边结构的 STEP 模型；
- 将外部模型设置为半透明参考基准，在布孔时直观避免阀体与机架管路发生机械干涉。

### 2. 标准孔腔库自定义扩展 (`.json` + 2D 轮廓)

- 允许企业根据内部工艺习惯扩充私有孔腔模板；
- 定义每阶台阶的直径、深度公差、螺纹规范及 O 形圈密封槽尺寸。
