# Import & Export Standards

SureFlow offers seamless interoperability across both enterprise CAD suites and lightweight web environments.

---

## Export Formats

- **STEP Solids (`.stp`, `.step`)**: ISO 10303-214 and 242 compliant solids with exact B-Rep cylindrical intersections for SolidWorks, NX, Creo, and CATIA.
- **GLB / glTF 3D (`.glb`)**: Optimized PBR models for web viewers, design reviews, and AR inspection.
- **Drilling Schedules (`.csv`, `.pdf`)**: Standardized tabular outputs covering port IDs, coordinates, approach vectors, diameters, and depths.
