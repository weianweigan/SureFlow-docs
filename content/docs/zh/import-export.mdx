# 导入与导出

SureFlow 具备工业级的互操作性，既支持主流机械 CAD 系统的实体交换，也支持前端轻量化 WebGL 交付。

---

## 支持的导出格式

### 1. STEP 实体文件 (`.stp` / `.step`)

- **标准支持**：
  - ISO 10303-214 (Automotive Design)
  - ISO 10303-242 (Managed Model Based 3D Engineering)
- **几何保真度**：精确 B-Rep 实体拓扑，圆柱面相贯曲线保留解析几何精度，无网格离散化变形；
- **下游兼容**：可直接导入 SolidWorks、Creo (Pro/E)、Siemens NX、AutoCAD 与 CATIA 中作为零件或总成装配。

### 2. GLB / glTF 3D 轻量化格式 (`.glb`)

- **应用场景**：网页在线 3D 评审、数字孪生系统、移动端查看器；
- **材质优化**：内置工业铝合金与锻钢 PBR 物理反射着色，自动压缩顶点缓冲区。

### 3. 加工工序参数表 (`.csv` / `.pdf`)

- 包含每一个钻孔编号、工作油口标签、X/Y/Z 空间起始坐标、打孔轴向矢量、孔径 $D$、深度 $H$、底孔锥角及沉孔规格。

---

## 导入工程与几何模型

- **SureFlow 工程文件 (`.sureflow`)**：保存完整的特征树、孔道逻辑连通图以及约束参数；
- **毛坯与基准参考导入**：支持导入客户装配环境中的结构件 STEP 模型作为避让参考体。
