# 安装与运行环境

SureFlow 为桌面原生软件，直接调用计算机本地图形硬件与多核 CPU 进行实时三维渲染与布尔几何运算。工程数据完全保存在本地磁盘，保障企业技术资料安全。

---

## 系统配置要求

| 硬件/系统组件 | 最低配置 | 推荐配置 |
| :--- | :--- | :--- |
| **操作系统 (Windows)** | Windows 10 64-bit (版本 1809 及以上) | Windows 11 64-bit |
| **操作系统 (macOS)** | macOS Monterey (12.0+) | macOS Sonoma (14.0+) 及以上 |
| **处理器 (CPU)** | 4 核心 x64 或 Apple M 系列 | 8 核心及以上多核处理器 |
| **显卡 (GPU)** | 支持 WebGL 2.0 / OpenGL 3.3 的集成显卡 | NVIDIA / AMD 独立显卡或 Apple M 系列统一内存 GPU |
| **内存 (RAM)** | 8 GB RAM | 16 GB 或以上（处理多通径复杂大阀块建议 32 GB） |
| **屏幕分辨率** | 1280 × 800 | 1920 × 1080（全高清）或更高分辨率显示器 |
| **存储空间** | 1 GB 可用固态硬盘空间 | 5 GB 极速 SSD 空间（用于存放大型装配工程） |

## 获取与安装方式

### Windows 用户 (`.exe`)

1. 前往 [下载中心](/zh/download) 或直接访问 [GitHub Releases](https://github.com/weianweigan/SureFlow/releases)；
2. 下载最新的 `SureFlow-Setup-x.y.z.exe` 安装包；
3. 双击运行安装向导，选择安装目录并完成安装；
4. 启动 SureFlow，首次运行会自动关联 `.sureflow` 阀块工程文件。

### macOS 用户 (`.dmg`)

> [!NOTE]
> 目前 macOS 官方安装包专注于 **Apple Silicon (M1/M2/M3/M4)** 原生架构优化，具备极佳的功耗控制与渲染流畅度。

1. 在下载中心或 GitHub Releases 获取 `SureFlow-x.y.z-arm64.dmg` 磁盘镜像；
2. 双击打开 `.dmg` 镜像，将 `SureFlow.app` 拖入系统的 `Applications`（应用程序）文件夹；
3. 首次打开如遇到系统未信任签名提示：
   - 前往 macOS **「系统设置」→「隐私与安全性」**；
   - 在页面下方找到针对 SureFlow 的拦截提示，点击 **「仍要打开」** 即可。

## 离线工作与数据安全

- **100% 离线可用**：SureFlow 的几何切削引擎、孔腔数据库及 STEP 导出模块全部内置于本地客户端，不依赖远程云端算力；
- **工业级数据私密**：阀块尺寸、油道走向、元件型号等商业设计参数均存储于用户本地的 `.sureflow` 工程或导出的 `.stp` 文件中，绝不向外部网络上传用户工程图纸。

---

## 软件版本检查与更新

- **软件内检查**：在客户端主菜单中点击 **「帮助」→「检查更新」**，客户端将在联网状态下静默比对最新稳定发行版本；
- **手动更新**：随时前往 [GitHub Releases](https://github.com/weianweigan/SureFlow/releases) 查阅各版本的变更日志（Changelog），下载新版本覆盖安装即可保持最新特性。
