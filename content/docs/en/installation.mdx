# Installation Guide

SureFlow distributions are distributed globally via Cloudflare Edge network proxies.

---

## Hardware & System Requirements

| OS | Minimum | Recommended |
| :--- | :--- | :--- |
| **Windows** | Windows 10 64-bit (1809+) | Windows 11 64-bit with dedicated GPU |
| **macOS** | macOS Monterey (12.0+) | macOS Sonoma (14.0+) / Apple Silicon M2/M3/M4 |
| **Memory** | 8 GB RAM | 16 GB+ (32 GB for blocks with 1000+ features) |
| **Storage** | 1 GB free SSD space | 5 GB NVMe cache |

---

## Installation Steps

### Windows (.exe)
1. Head to the [Download Center](/en/download) and download `SureFlow-Setup-x.y.z.exe`;
2. Run the installer and follow on-screen prompts;
3. SureFlow associates with `.sureflow` project files automatically.

### macOS (.dmg)
1. Download `SureFlow-x.y.z-arm64.dmg` tailored for Apple Silicon;
2. Open the disk image and drag `SureFlow.app` into your Applications folder;
3. If macOS Gatekeeper alerts about unsigned apps, allow it in **System Settings → Privacy & Security**.
